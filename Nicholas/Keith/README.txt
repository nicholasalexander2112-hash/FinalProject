PIXEL QUEST — TCCNY GYM
=======================
An offline-friendly, original Pokémon-inspired interactive website based on the uploaded entrance reference.

HOW TO PLAY
1. Open index.html in Chrome, Edge, Firefox or Safari. (A local server is recommended for offline install.)
2. Click START ADVENTURE for an automatic walk to the gym, or EXPLORE MYSELF to control the trainer.
3. Manual movement: arrow keys / WASD, interact E / Enter / Space. On mobile, use the on-screen D-pad and A button.
4. At the gym, choose an original companion, challenge Stoneback, and unlock the Beacon Badge.
5. Your progress is saved in the current browser using localStorage.

OPTIONAL LOCAL HOSTING
From this folder run: python -m http.server 8000
Then visit http://localhost:8000 in your browser.

Files are original, created for this demo. No official Pokémon sprites or assets are included.
No external services or accounts are required. Audio is muted by default and can be turned on in the gym.
